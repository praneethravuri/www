# Praneeth Ravuri — praneethravuri.com

Personal portfolio. Built with Next.js, React 19, Tailwind v4, and TypeScript.

**Live:** https://praneethravuri.com

## Commands

```
pnpm dev      — dev server
pnpm build    — production build (TypeScript strict)
pnpm lint     — ESLint
pnpm analyze  — bundle analysis
```

Content (bio, work, projects, education) lives in `app/data/resume.tsx`.

## About

This repo is the source for my personal portfolio site: bio, work history, projects, and skills.

## Commands

```
pnpm dev          — dev server (Turbopack)
pnpm build        — production build
pnpm start        — start production server
pnpm typecheck    — tsc --noEmit (strict)
pnpm lint         — ESLint (type-aware)
pnpm lint:fix     — ESLint autofix
pnpm check        — typecheck + lint
```

Content (bio, work, projects, skills, contact) lives in `src/data/resume.tsx`.

## Stack

Next.js (App Router), React 19, TypeScript, Tailwind v4, shadcn/ui (Radix primitives), Magic UI (motion), react-markdown, react-github-calendar.

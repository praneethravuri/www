# Praneeth Ravuri’s portfolio

A static Next.js portfolio with a dark palette and an animated Blobatar. Content is maintained in `app/data/resume.tsx` and shared by the page, metadata, structured data, and Markdown portfolio.

## Development

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm lint
pnpm build
pnpm test:seo
pnpm test:headers
pnpm test:agents
```

`/llms.txt` follows llms.txt v2 and links to the full portfolio at `/index.md`, agent guidance, trust pages, and project README resources. All published HTML pages have static Markdown alternatives at `/index.md` or `/<page>/index.md`. About, Contact, Privacy, Projects, and Agent Instructions share their HTML and Markdown content from `app/data/resume.tsx`.

`proxy.ts` negotiates HTML and Markdown with the HTTP Accept parser `negotiator`, respecting quality values and explicit rejections. It adds `Vary: Accept, Accept-Encoding`, returns 406 for unsupported representations, and gives missing Markdown paths a real 404 with recovery links. Next internals, icons, generated images, crawler files, and Vercel telemetry routes bypass negotiation. The homepage remains statically prerendered; no request-dependent React rendering or new client island is required.

`patches/next@16.3.8.patch` preserves existing Vary headers when Next’s HTML runtime adds its RSC headers, and includes Accept/Accept-Encoding in the static routing manifest consumed by Vercel. Without it, the runtime and static delivery paths overwrite the variation added by the proxy. Keep the regression checks and remove the version-specific patch when an upstream release preserves the headers correctly.

Share images, robots.txt, and sitemap.xml are generated by Next.js. `pnpm test:agents` starts a temporary production server and checks HTTP behavior and every published page, Markdown route, crawler file, share image, and icon. Set `AGENT_TEST_ORIGIN` to check an accessible deployment instead. For a protected branch preview, set `AGENT_TEST_DEPLOYMENT` to its URL; the checks use the authenticated Vercel CLI without reading or logging bypass tokens.

Search indexing and name-based ranking need time, consistent external profile links, and Search Console verification/submission. This personal portfolio does not offer a public API or hosted MCP server; project repositories contain their own setup instructions. Organization schema should be added only if the publisher becomes an actual organization with confirmed public details.

Pre-commit runs formatting and linting on staged files, then checks types when TypeScript is staged. CI runs formatting, lint, dependency audit, build, SEO checks, and agent endpoint checks.

The Blobatar follows the pointer and can be paused by clicking it or pressing Enter when focused. Motion respects the system’s reduced-motion preference.
